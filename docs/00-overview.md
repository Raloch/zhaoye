# 照夜封魔录 · 设计总览

> 工作名《照夜封魔录》，英文代号 `zhaoye`。游戏名和角色名都可以改。

## 一句话

少年剑客叶昭手持「照夜剑」，一路破尽幻术，揭穿魔族右护法蜃楼的篡位阴谋，救出被囚的魔君，守住维系了三百年的人魔之盟。

## 基本信息

| 项 | 设定 |
|---|---|
| 类型 | 横版动作 ARPG：关卡推进 + 锁屏遭遇战 + 搓招连段 |
| 视角 | 2D 侧视，单平面（没有清版街机那种纵深走位），有单向平台 |
| 平台 | PC 浏览器。键盘为主，手柄其次，移动端触屏放到后期 |
| 操作 | 沿用参考作的 WASD 移动、J 攻击、K 跳、L 防御、I 道具；新增 U 照夜、O 奥义 |
| 规模 | 5 章，每章 10～15 分钟，首通约 60～90 分钟；另有 Boss 连战和无伤挑战 |
| 美术 | 国风水墨剪影 + 霓光剑气（参考《影之刃》《忍者必须死》） |
| 技术 | TypeScript + Vite + Canvas 2D，零运行时依赖，沿用 adder 的「纯逻辑 core」分层 |

## 设计支柱

1. **连招爽快**：地面起手 → 挑空 → 空中追击 → 坠星弹地 → 再挑，能一路连下去。手搓指令比快捷键省灵力；招式用得越杂，剑意涨得越快。
2. **读招反击**：敌人出招前都有颜色预警（白色可挡，红色必须闪，紫色是幻术）。格挡、弹反、闪步各有明确回报，Boss 战考验看破时机的能力。
3. **照夜破幻**：本作的差异化机制。照夜剑能照出幻象：平台的真假、敌人的真身、Boss 的分身、NPC 是否被操控。这个机制同时服务剧情（破除成见）、关卡（幻象平台）和战斗（剥幻甲）。
4. **水墨剪影**：角色用剪影加少量点缀色，背景是程序生成的层叠水墨山水。风格统一，一个程序员就能量产，不依赖外包美术。

## 核心循环

```
┌─────────────────────── 章节 ───────────────────────┐
│  探索推进 → 锁屏遭遇战 → 平台/机关 → …… → 章末 Boss  │
│      ↑ 灵石 / 经验 / 剑谱残页         ↓ 剧情 + 新招式  │
└──────────── 营地：商店 · 悟道 · 饰品 ←───────────────┘
```

- **秒级**：看预警 → 格挡、闪步或弹反 → 打出硬直 → 连段 → 攒剑意 → 奥义收尾。
- **分钟级**：一场锁屏战 30～90 秒。战斗之间穿插平台、机关和隐藏点，节奏有张有弛。
- **章节级**：每章学一个新特技，配一个专门考这招的 Boss。章末结算评级（甲乙丙丁）。

## 范围

**要做**：5 章主线、10 种杂兵、6 场 Boss 战（第 5 章是两阶段）、5 个特技 + 照夜 + 奥义、轻度 RPG 成长（等级、悟道、饰品）、商店、章节评分、难度选择、按键重映射、招式表。

**首版不做**：联机、纵深走位、开放世界、刷装备词条、多角色可选、剧情分支。

## 待你确认的关键决策

下面几项我先定了默认值，想改哪条直接说。

1. **美术风格**：默认水墨剪影。剪影可以用骨骼动画在代码里量产；像素风更像传统横版，但需要外部美术或素材包。详见 [06-art.md](06-art.md) 第 1 节。
2. **平台**：默认浏览器 + 键盘。手柄在 M6 加，触屏暂不做。
3. **规模**：默认 5 章。如果想先做短一点，可以砍成 3 章，[01-story.md](01-story.md) 末尾有压缩方案。
4. **名字**：游戏名、主角名、反派名都是暂定。
