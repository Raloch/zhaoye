# 世界观与剧情

## 世界观

### 地理

```
                         【蜃楼幻宫】 悬在幽泽上空的海市蜃楼，蜃楼的老巢
                               ☁
【青州 · 人界】 ──── 断岳山 · 镇魔碑 ──── 【幽泽 · 魔域】
 青崖镇、青崖观          （人魔边界）          魔族村落、幽泽关
 雾隐竹林                    │
                     九幽：封着上古凶物「烛幽」
```

- **青州**：人族边陲，山清水秀。青崖镇是人魔互市的集镇，镇后青崖山上有青崖观，历代人族守碑人都出自这里。
- **断岳山**：人魔两界的分界山脉，镇魔碑立在山脊上。
- **幽泽**：魔族领地，终年起雾，水泽纵横。魔族并不邪恶，大多是靠打渔、采药过日子的普通妖民。
- **九幽**：断岳山地底。上古凶物「烛幽」被封在这里。它以怨念为食，一旦醒来会吞尽两界的光。

### 历史：碑盟

三百年前烛幽出世，人魔两族都险些灭族。人族剑仙**沈寒川**和魔族先君**玄穹**联手，用照夜剑和魔君之血把烛幽封在断岳山下，立起镇魔碑，订下「碑盟」：

> 人魔不相犯；碑南碑北，各守一脉。

人族守碑人世代出自青崖观，魔族守碑人由历代魔君亲任。照夜剑一直供奉在青崖观。三百年来边境相安无事，青崖镇也成了人魔互市的地方。

**大多数人不知道的是**，碑下镇的不是魔族，而是烛幽。年代久了，人族中流传起「镇魔碑镇的是魔族」的说法，成见由此而生。

### 势力

| 势力 | 立场 | 代表人物 |
|---|---|---|
| 青崖观 | 守碑，中立 | 玄一真人、叶昭 |
| 青崖镇民 | 与魔族通商，但心存戒备 | 镇长、铁匠老周 |
| 魔族王庭 | 守盟，主和 | 魔君玄霜、左护法骨刹 |
| 蜃楼一党 | 篡位，想吞下烛幽的力量 | 右护法蜃楼，以及被他操控的黑鬃等妖物 |

### 反派动机

蜃楼是千年蜃妖，精通幻术。他认为魔族被碑盟困在沼泽里三百年，等于在「替人族看门」。他的计划分三步：

1. 用幻术把魔君玄霜囚在镜狱，自己化成她的样子发号施令；
2. 驱使没有灵智的低阶妖物袭击人族城镇，打着「魔君有令」的旗号挑起两族大战；
3. 战争产生的怨气会侵蚀镇魔碑，等碑一碎，他就吞下烛幽，成为新的魔神。

他不是疯子，他真心相信自己在解放魔族。这让结局的对峙有分量。

## 主题：照见真实

照夜剑能照破幻术，叶昭的成长线就是一次次**看穿表象**：

- 第 1 章：他相信「魔族背盟」，被表象骗了；
- 第 2 章：他用照夜剑照一只魔族小妖，想证明对方说谎，结果照出来的是真话，他开始动摇；
- 第 4 章：他走进魔族村落，看到的是和青崖镇一样的寻常人家，成见被打破；
- 第 5 章：他看穿蜃楼最大的幻术：「人魔注定为敌」。

**机制和主题是同一件事**。玩家每按一次 U 照亮真相，都在重复这个主题。

## 主线梗概（三幕）

- **第一幕（第 1～2 章）**：青崖镇遇袭，玄一真人重伤，把照夜剑交给叶昭。叶昭追到雾隐竹林，救下魔君的信使小蝠，得知魔君被囚、有人冒名作乱。
- **第二幕（第 3～4 章）**：叶昭赶到断岳山，镇魔碑已经开裂。他在碑前看到三百年前的记忆，得知烛幽的存在。随后深入幽泽，在魔族村落放下成见，击败被幻术控制的左护法骨刹，打通前往幻宫的路。
- **第三幕（第 5 章）**：闯入蜃楼幻宫，从镜狱救出玄霜，两人合力击败蜃楼。碑裂之际，蜃楼化出蜃龙真身想吞下烛幽，最终被叶昭和玄霜斩落，碑盟重订。

## 分章剧情

### 第 1 章「烽起青崖」

- **地点**：青崖镇，黄昏到入夜，镇上起火。
- **开场**：叶昭在镇外山道练剑（教学关），远处镇上升起狼烟。他赶回去时，狼妖已经冲进集市。
- **流程**：镇外山道 → 镇口牌坊（锁屏战）→ 集市长街（火场、救镇民）→ 屋顶（平台、鬼火）→ 镇祠广场（Boss）。
- **Boss 黑鬃**：狼妖头目，战前咆哮「魔君有令，人族背盟，屠尽青崖！」
- **结尾**：黑鬃倒下时，眼中的紫光散去，神情茫然：「我……为何在此……」屋檐上一个紫衣人影一闪而过（蜃楼的幻影），一道紫雷劈向叶昭。玄一真人赶到替他挡下，身受重伤。他把照夜剑交给叶昭：「剑能照夜，也能照人心。去断岳山，看看碑……」
- **解锁**：照夜（U）、奥义「照夜·破晓」（O）。叶昭从这里开始用照夜剑，之前用的是铁剑。
- **叶昭此时的认知**：魔族背盟了。

### 第 2 章「雾锁竹林」

- **地点**：雾隐竹林，白天起雾，后来下雨。雾里夹着淡淡的紫色（蜃气，为后文埋伏笔）。
- **流程**：竹林入口 → 竹海（竹台、竹刺）→ 溪谷（救小蝠）→ 雾径（照夜显路）→ 古树祭坛（Boss）。
- **关键事件：救小蝠**。一只蝙蝠小妖被狼妖和蛊蛾追杀。叶昭本不想管（「魔族的事，与我何干」），可追兵也冲着他来了。战后小蝠说魔君被囚、有人冒名。叶昭不信，拿照夜剑照他，**这里就是 U 键的教学**。剑光下的小蝠既不是幻象，也没有被操控，说的是真话。
- **Boss 枯藤姥姥**：竹林里的古树精，原本是这片林子的守护者，被蜃气侵蚀后发了狂。
- **结尾**：蜃气退去，姥姥恢复神智，赠叶昭「藤风之息」（二段跳）。小蝠决定跟着叶昭：「我、我是去给魔君报信，不是跟着你！」从这一章起，小蝠在营地开店。
- **解锁**：剑气·破月（雾径里的剑谱残页）、二段跳。
- **叶昭此时的认知**：也许真有人冒名，但魔族还是信不过。

### 第 3 章「碑裂断岳」

- **地点**：断岳山，冷灰色的石山，地底裂缝透出暗红色的光。
- **流程**：山道栈道（落石、弓手）→ 吊索桥（大风）→ 碑林（石傀儡）→ 裂隙洞窟（地火）→ 镇魔碑前（Boss）。
- **Boss 镇岳**：守碑的石像将军，被蜃气附身后攻击一切靠近的人。
- **关键事件：碑前回忆**。击败镇岳后，叶昭把照夜剑插进碑的裂缝，暂时稳住封印。剑光中浮现三百年前的记忆，**这是一段 30 秒的可操作回忆战**：玩家操作沈寒川，招式全开、灵力无限，和魔君玄穹并肩对抗烛幽的触手。它既揭示剧情，也让玩家提前看到满配的叶昭能打到什么程度。
- **结尾**：叶昭明白碑下镇的是烛幽，人魔本是盟友。小蝠：「我就说嘛！」镇岳恢复神智，说出三个词：「右护法……蜃楼……幻宫……」
- **解锁**：升龙斩（裂隙洞窟里的残页）。
- **叶昭此时的认知**：真正的敌人是蜃楼，但他对魔族的戒心还没完全放下。

### 第 4 章「幽泽幻海」

- **地点**：魔域幽泽，紫色暮光，天边漂着海市蜃楼。
- **流程**：幽泽边缘（沼泽、浮叶）→ **魔族村落（和平区，没有战斗）** → 幻雾迷径（幻象平台、幻影魔兵）→ 幽泽关（Boss）。
- **关键事件：魔族村落**。小蝠的娘给叶昭盛鱼汤。村里有卖药的、打渔的、吵架的夫妻；孩子们在玩「剑客打魔头」，演魔头的孩子哭着不肯演。叶昭沉默了很久。这是全篇唯一没有战斗的关卡，是最终决战前的喘息。
- **支线**（可选）：帮村民找回走失的小妖，奖励饰品「蝠翼铃」。
- **Boss 骨刹**：魔族左护法，忠诚的武人，被蜃楼的幻术蒙蔽，以为叶昭是入侵的人族先锋。进入二阶段后他的刀开始犹豫（「这一刀……为何……」）。
- **结尾**：照夜剑照破骨刹身上的幻术。骨刹跪地：「我竟替逆贼守门……」他打开幽泽关，指明幻宫的方向，自己留下断后。
- **解锁**：疾风连斩（幻雾迷径里的残页）。
- **叶昭此时的认知**：魔族和人族没有分别。

### 第 5 章「蜃楼幻宫」

- **地点**：悬在幽泽上空的幻宫，紫金色调，到处是镜子，宫殿倒挂在空中。
- **流程**：宫门（幻影车轮战，前四章的敌人化作幻影重现）→ 镜廊（镜魅、光路解谜）→ 倒悬殿 → 镜狱（救玄霜）→ 幻宫天台（Boss 蜃楼）→ 云海（Boss 蜃龙）。
- **关键事件：镜狱**。玄霜被封在四面镜子中间，每面镜子都映出一个「玄霜」，只有一个是真的。叶昭用照夜剑找出真身，击碎四面镜封。玄霜：「人族的守碑人……三百年了，你们还记得碑盟。」
- **Boss 蜃楼**：人形阶段，幻术师，会分身、召镜子、让全场陷入黑暗。
- **Boss 蜃龙**：蜃楼吸收了碑下逸出的烛幽之力，化作巨大的蜃龙。战场是正在崩塌的云海浮台。玄霜在场边支援，定时冻结蜃龙，给玩家创造输出窗口。
- **终幕**：蜃龙倒下时，碑的裂缝已经大开。叶昭和玄霜效仿先辈，以照夜剑加魔君之血重新封印烛幽。这是按住 J 的演出式 QTE，不会失败。
- **解锁**：镇地剑（宫门的残页）；救出玄霜后，奥义升级为「照夜·霜月」。

### 尾声

- 青崖镇重建，魔族商队又来赶集。玄一真人伤愈，把守碑人之位传给叶昭。
- 小蝠在镇上开了铺子，招牌写着「人魔童叟无欺」。
- 片尾彩蛋：断岳山地底，一只巨大的眼睛缓缓睁开。

## 叙事手法（控制制作成本）

- **过场**：水墨分镜卷轴（静态插画 + 镜头推移 + 字幕），不做动画过场。
- **对话**：底部对话框，左右两侧是剪影立绘加点缀色，按 J 或回车推进，可跳过。
- **关卡内对话**：头顶气泡，不打断操作，例如小蝠在战斗中喊「右边！右边！」。
- **文本量**：每章约 30～60 句。

## 压缩方案（如果只做 3 章）

- 第 1 章不变；
- 第 2、3 章合并为「断岳」：竹林改成去断岳山的路，救小蝠和碑前回忆都放在这一章；
- 第 4、5 章合并为「幻宫」：魔族村落缩成一段过场，骨刹改为幻宫中段 Boss，最终 Boss 不变。
