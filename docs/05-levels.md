# 地图与关卡

## 1. 世界地图

一幅水墨长卷，从左（南）到右（北）展开：

```
青崖镇 ──→ 雾隐竹林 ──→ 断岳山 ──→ 幽泽 ──→ 蜃楼幻宫（悬在幽泽上空）
 第1章        第2章        第3章      第4章         第5章
   │
 青崖观（营地）
```

- 章节之间回到**营地**（第 1～3 章在青崖观，第 4 章起在魔族村落）：商店、悟道（升级招式）、饰品、试剑（重玩打过的遭遇战）。
- 通关的章节可以重玩，用来刷评级、收集残页。

## 2. 关卡结构

### 规格

- **图块**：16×16 逻辑像素。
- **一屏**：480×270，即 30 列 × 16.9 行。关卡高度一般是 17 行（一屏）；有垂直段落的地方（竹海、倒悬殿）更高，摄像机上下跟随。
- **长度**：每章 10～15 屏。

### 段落类型

| 类型 | 说明 | 摄像机 |
|---|---|---|
| 推进段 | 自由前进，零散的敌人 | 跟随，前方留 40% 视野 |
| 锁屏战 | 进入后两侧升起墨障，打完所有波次才能继续 | 锁定 |
| 平台段 | 跳跃、机关、陷阱 | 跟随，含垂直跟随 |
| 和平区 | 没有战斗，NPC 对话、商店 | 跟随 |
| Boss 场 | 一屏大小的固定场地 | 锁定 |

### 节奏原则

- 每场锁屏战之后，接一段 20～40 秒的低强度段落（平台、剧情、收集）。
- 新敌人先**单独**出场一次，让玩家在安全环境里认识它，再和老敌人混编。
- 新特技在 Boss 之前至少有一场锁屏战能用上。
- Boss 前一定有检查点（灯笼）。

### 通用元素

| 元素 | 说明 |
|---|---|
| 灯笼（检查点） | 点亮后，死亡从这里复活，同时回复 30% 生命 |
| 灵石罐 | 打碎掉灵石 |
| 剑谱残页 | 每章 1 张主线残页（解锁新特技）+ 2 张隐藏残页（招式升级材料） |
| 试剑石 | 隐藏的限时挑战，例如「10 秒内打出 30 连击」，奖励饰品 |
| 墨障 | 锁屏战两端的屏障，由浓墨构成，碰到会被弹回 |

```
 └──────────────────────────────────────────────▶ 屏
    教学     锁屏      平台      锁屏      平台 灯笼
```

## 5. 关卡数据格式

关卡用**文本**存：人能直接读，diff 清楚，也方便我直接编写。

### 图块层：ASCII，每屏 30 列 × 17 行

```
图例
.  空              #  实地          =  单向平台（屋檐、摊棚、竹台）
^  伤害地面（火、竹刺、荆棘）        ~  沼泽 / 水
P  出生点          C  灯笼（检查点）  D  可破坏的门
$  灵石罐          ?  剑谱残页       !  教学提示
w  灰狼            f  鬼火           g  狼卫        t  稻草人
B  Boss            N  NPC
```

### 实体层：结构化数据

```ts
arenas: [
  {
    id: '1-2',
    cols: [60, 90],          // 锁屏范围（图块列，左闭右开）
    waves: [
      [{ type: 'wolf', count: 3, side: 'both' }],
      [{ type: 'wolf', count: 2, side: 'right' }, { type: 'wolfGuard', count: 1, side: 'right' }],
    ],
    hint: 'guardBreak',      // 第一次进入时的教学提示
  },
]
```

图块层画地形，实体层描述「什么时候、在哪、刷什么」。波次、教学提示、剧情触发都放在实体层，调数值不用改地图。

以后关卡多了，可以改用 Tiled 编辑器，导出 JSON 后写个脚本转换。

## 6. 场景分层（视差）

| 层 | 视差系数 | 内容 |
|---|---|---|
| 天空 | 0 | 渐变，加日或月 |
| 远山 | 0.1 | 程序生成的水墨山脊，最淡 |
| 中景 | 0.3 | 章节标志物：塔、竹林、断崖、蜃楼 |
| 近景 | 0.6 | 建筑、树木剪影 |
| 游戏层 | 1.0 | 地形、角色、敌人 |
| 前景 | 1.3 | 少量遮挡（草、竹叶、栏杆），半透明，不挡关键信息 |
