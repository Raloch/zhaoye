# 怪物与 Boss

> 视觉草图见视觉设定集 `concept/index.html` 的「怪物」「Boss」两节。

## 通用 AI 框架

### 行为状态机

```
待机 → 发现玩家 → 接近 / 保持距离 → 申请「攻击令牌」→ 预警 → 出招 → 收招（惩罚窗口）→ 回到接近
                                           │ 没拿到令牌
                                           └→ 绕圈、低吼、后撤
任何状态下被击中 → 受击状态 → 恢复
```

### 攻击令牌

同一时间只有 N 个敌人可以向玩家出招（普通难度 N = 2），其余的在外圈游走、低吼、摆架势。这是清版动作游戏的公平底线：画面上可以有 8 只狼，但不会同时被 8 只咬。

- 令牌优先给离玩家最近、在屏幕内、等得最久的敌人。
- 飞行和远程敌人单独一个令牌池，最多 1 个。
- Boss 不受令牌限制，但 Boss 召唤出来的小怪受限制。

### 韧性（霸体）

- 每个敌人有**韧性值**。每次命中扣韧性：普攻 10，重击 25，蓄力斩 50。
- 韧性大于 0 时，敌人在「霸体招式」中不会被打断（但照样掉血）。
- 韧性归零：小怪直接被打断；大型敌人和 Boss 进入**破韧**，虚弱 3～4 秒，受伤 +30%。
- 2 秒没挨打，韧性开始回复。

## 数值说明

HP 和攻击以**首次出场的章节**为准。之后的章节再出场时乘以章节系数（第 1～5 章：×1.0 / ×1.4 / ×1.9 / ×2.4 / ×3.0）。攻击力按同期玩家血量的百分比设计（见 [09-systems.md](09-systems.md)），表里给的是绝对值。

### 1. 灰狼妖（第 1 章）

- **外形**：灰黑色的狼，四足，比真狼大一圈，眼睛泛红光。被蜃气操控的，眼里还带一点紫。
- **行为**：成群出现（3～5 只）。在玩家 60～90 px 外绕圈，拿到令牌的那只发起攻击，会主动绕到玩家背后。
- **招式**：
  - 扑咬（白）：伏低 18f，然后向前扑 72 px。扑空后原地硬直 30f（惩罚窗口）。
  - 撕咬（白）：贴身两连咬，起手 12f。
- **弱点**：被挑到空中后完全无法反抗，是上挑教学最好的沙包。

### 2. 鬼火（第 1、4 章）

- **外形**：一团长着眼睛的青色火焰，飘在半空（离地 48～96 px）。
- **行为**：在玩家头顶附近游荡，拿到令牌就俯冲。
- **招式**：
  - 俯冲（白）：身体变亮 24f，然后斜着冲向玩家脚下，落地炸开一小团火。
  - 火球（白）：慢速火球，速度 2 px/f，可以被剑气抵消。
- **设计意图**：逼玩家跳起来打，或者用上挑。一两下就死，主要作用是「烦人」。
- **第 4 章变种「蜃火」**：紫色，一半是幻象（打不中，也伤不了人），用照夜可以分辨。

### 3. 狼卫（第 1 章）

- **外形**：直立的狼人士兵，一手木盾，一手弯刀。
- **行为**：举盾推进，正面挡住普攻（格挡时冒火花，不掉血）。
- **招式**：
  - 横斩（白）：起手 16f。
  - 盾击（白）：贴身顶一下，能打断玩家的连段。
  - 举盾：正面免疫普攻，但会被断岳、蓄力斩、穿云刺破防（破防后硬直 40f）。
- **设计意图**：让玩家第一次意识到「光按 J 不行」。

### 4. 藤精（第 2 章）

- **外形**：会走路的老树桩，两条藤蔓当手，树洞里一对绿眼（被侵蚀的是紫眼）。
- **行为**：慢而重，走到中距离就停下来施法。
- **招式**：
  - 地刺（白）：玩家脚下先冒 30f 尘土，然后钻出藤刺。
  - 藤鞭（白）：中距离横扫，范围 80 px，要跳起来躲。
  - 缠绕（红）：藤蔓贴地向前蔓延，碰到就被缠住 1 秒（连按左右键挣脱）。
- **霸体**：出招时有霸体（韧性 60），要么等它收招再打，要么用重击削韧。

### 5. 蛊蛾（第 2 章）

- **外形**：翅展很大的飞蛾，翅膀上有眼状斑纹（点缀色是病态的黄绿）。
- **行为**：在高处盘旋，玩家一靠近就飞走，保持距离撒毒粉。
- **招式**：
  - 毒粉（白）：在下方留下一片毒雾，持续 4 秒，每秒扣 2% 血量。
  - 召唤：少数精英蛾会召来 2 只小蛾。
- **设计意图**：配合第 2 章解锁的剑气·破月，给玩家一个「远程打飞行单位」的理由。

### 6. 骷髅兵（第 3 章）

两个变种共用一套骨架：

- **刀兵**：三连斩（白），起手 14f。**被打散后 5 秒内会重新拼起来**，除非在散架时用追地攻击（坠星、扫堂、镇地剑）打碎。
- **弓手**：站在高处放箭（白，箭可以被弹反打回去）。玩家一靠近就后跳拉开距离。血很少，近身就死。
- **设计意图**：刀兵教追地攻击；弓手教用穿云刺、疾跑近身。

### 7. 石傀儡（第 3 章）

- **外形**：大块岩石拼成的人形，背后嵌着一枚发红光的符文。
- **行为**：极慢，全程霸体。
- **招式**：
  - 重拳（白）：起手 24f，命中就击飞。
  - 砸地（红）：双拳高举 36f 后砸地，向两侧打出冲击波，只能跳或闪步躲。
  - 冲撞（红）：蓄力后直线冲过半个屏幕。
- **弱点**：背后的符文。从背后打伤害 ×2、削韧 ×2。闪步穿过去就能绕到背后。
- **破韧后**：跪倒 4 秒，符文完全暴露。

### 8. 沼蛙妖（第 4 章）

- **外形**：矮胖的直立蛙妖，大嘴，背上长着疣。
- **行为**：常常高高跳起，从空中砸下来。
- **招式**：
  - 高跳砸（白）：跳到玩家头顶，影子先落到地上，然后砸下。它起跳后可以用升龙斩在半空截住。
  - 吐舌（红）：舌头伸出 120 px，抓住玩家就拉到嘴边吞下（持续伤害，连按挣脱）。
  - 肚撞（白）：贴身。
- **设计意图**：第 4 章正好是玩家熟练运用升龙斩（第 3 章解锁）的时候。

### 9. 幻影魔兵（第 4、5 章）

- **外形**：半透明的紫色魔族士兵，披甲持戟，轮廓闪烁。
- **机制**：
  - **幻甲**：受到的伤害 −80%。被照夜光扫过后，幻甲剥落 6 秒，变成实体。
  - **假兵**：一组里有几个是纯幻象，攻击不造成伤害，但看起来和真的一样。被照夜照到就消散。
- **招式**：
  - 三连戟（白）。
  - 瞬身斩（紫）：消失，然后在玩家背后出现并斩击。紫色预警在玩家背后亮起。
- **设计意图**：U 键在战斗中的主场。

### 10. 镜魅（第 5 章）

- **外形**：由镜子碎片拼成的人形，脸是一面光滑的镜子。
- **机制：模仿**。镜魅记住玩家最近用过的 3 个特技，隔一段时间就用同样的招式反打（伤害较低，但能打断玩家）。
- **弱点**：被照夜照到会僵直 1 秒。
- **设计意图**：最后一章检验玩家的招式多样性。只会一招的人，会被自己那招打得很惨。

## Boss

### 通用规则

- 血条在屏幕底部，带阶段分割线和韧性条。
- 每个 Boss 两个阶段，转阶段时有 2 秒演出（Boss 无敌，场上小怪清空）。
- 每个大招收招后都有**明确的惩罚窗口**：Boss 喘气、卡住或跪地。
- 被击败时：慢动作、黑白冲击帧、墨溅炸开。

### B1 黑鬃（第 1 章）

- **外形**：黑鬃狼人，高 72 px，驼背，颈上一圈钢针般的鬃毛，爪子很长。眼里有紫光（被操控）。
- **HP** 1000，**韧性** 100。
- **场地**：镇祠广场，平地，两侧各有一座石灯台（可以跳上去，高 32 px）。

| 阶段 | 招式 | 预警 | 惩罚窗口 |
|---|---|---|---|
| 一（100%～50%） | 扑击三连：连续三次扑咬，第三次带红光 | 白、白、红 | 第三扑之后喘气 50f |
| | 横扫爪：身前大范围横扫 | 白（用来教弹反） | 20f |
| | 嚎叫：召唤 2 只灰狼（冷却 20 秒） | 仰头 40f | 嚎叫期间可以打 |
| 二（50%～0） | 狂暴：速度 +20%，眼光变红 | 转阶段演出 | —— |
| | 天坠：跳出画面，影子追踪玩家 2 秒后砸下 | 红（地上的影子） | 爪子插进地里 60f |
| | 连爪五连：最后一下击飞 | 白 | 30f |

- **教学点**：看预警 → 闪步躲红光 → 抓住惩罚窗口输出。

### B2 枯藤姥姥（第 2 章）

- **外形**：一棵巨大的古树，树干上是一张老妇人的脸，垂下的枯藤像长发，两条粗藤是手臂。胸口有一颗紫色的核，是侵蚀的源头。高约 140 px，固定在场地右侧。
- **HP** 1500；固定 Boss，没有韧性。
- **机制**：本体有幻甲（−80%）。**用照夜照中心核**，心核暴露 8 秒，此时打心核伤害 ×1.5。心核离地 72 px，需要跳起来打，或者用剑气。
- **场地**：古树祭坛，中间是平地，两侧各有两层竹台。

| 阶段 | 招式 | 预警 | 应对 |
|---|---|---|---|
| 一 | 地刺连环：从树根开始，朝玩家一路冒出藤刺 | 地面冒尘土，白 | 往回跑，或跳上竹台 |
| | 藤臂横扫（贴地） | 藤臂贴地向后拉，白 | 跳 |
| | 藤臂下砸 | 藤臂高举，白 | 闪步；砸完后藤臂趴在地上 60f，可以砍（打藤臂伤害 ×0.5 算给本体） |
| | 孢子弹：抛物线弹幕 | 树冠发光 | 走位，或用剑气抵消 |
| 二（50%） | 荆棘满地：场地中央长满荆棘（碰到掉血），只能在竹台上活动 | 转阶段 | —— |
| | 召唤 2 只蛊蛾 | —— | 用剑气清掉 |
| | 枯藤缚：藤蔓从天而降，锁住一座竹台 | 竹台变紫，红 | 换一座竹台 |

- **教学点**：照夜在战斗中的用法；利用平台；远程攻击（剑气）。

### B3 镇岳（第 3 章）

- **外形**：守碑的石像将军，高 128 px，全身石甲，头盔上一道冠羽，手持一柄石制大刀。裂缝里透出红光（烛幽的气息）。
- **HP** 2400，**韧性** 300（韧性条单独显示在血条下方）。
- **机制**：全程霸体。韧性打空后跪地 4 秒，头部降到够得着的高度，正好用空中连段（升龙斩在这里大显身手）。
- **场地**：镇魔碑前的石台，平地，背景是巨大的镇魔碑。

| 阶段 | 招式 | 预警 | 应对 |
|---|---|---|---|
| 一 | 横斩：大刀贴地横扫，覆盖身前 160 px | 刀向后拉 30f，白 | 跳，或弹反（弹反削韧 40） |
| | 纵劈：劈下后沿地面打出一道冲击波 | 刀高举 30f，白 | 跳过冲击波 |
| | 岩刺：地面依次冒出三排石刺 | 地面开裂，白 | 读节奏走位 |
| | 碑印：手掌发红光，抓住玩家往地上砸 | 红 | 闪步 |
| 二（40%） | 碑文亮起，攻速 +15% | 转阶段 | —— |
| | 落石：头顶掉石头 | 地上的影子 | 走位 |
| | 横斩接纵劈（组合技） | 白 → 白 | 跳 → 再跳 |

- **教学点**：韧性和破韧；对空（升龙斩）；读组合技。

### B4 骨刹（第 4 章）

- **外形**：骷髅武将，高 60 px，双持弯刀，破披风，弯角盔。
- **HP** 3000，**韧性** 150。
- **机制**：
  - **会弹反**：玩家连续用同一种普攻打他 3 次以上，他就弹反（白光一闪，玩家硬直）。逼着玩家混用招式。
  - **二阶段幻影**：他会分出 2 个幻影一起进攻，只有真身有实体，用照夜可以分辨。
- **场地**：幽泽关前的石桥，平地，一端是关门，一端是断崖（有锁屏边界，不会被打出场外）。

| 阶段 | 招式 | 预警 | 应对 |
|---|---|---|---|
| 一 | 双刀连斩（4 段） | 白 | 格挡，或弹反第 4 段 |
| | 瞬步：冲刺穿过玩家，到背后回身斩 | 身体前倾，白 | 转身防御 |
| | 回旋刀：掷出双刀，像回旋镖一样飞回来 | 白 | 刀去时跳过，刀回时闪步 |
| | 骨刺：地面冒出一排骨刺 | 白 | 跳 |
| 二（50%） | 怨魂附体：刀上带红光，所有斩击都变成红光 | 转阶段 | 只能闪步；但他每连斩 5 次就要喘一口气 |
| | 三身幻影：分出 2 个幻影，同时发动瞬步 | 紫 | 用照夜找真身 |

- **剧情化的 AI**：二阶段每次打完红光连斩，有 20% 的概率收招变慢，并说出「这一刀……为何……」，给玩家额外的输出窗口，暗示他在挣扎。

### B5 蜃楼（第 5 章，一阶段）

- **外形**：见角色设定。战斗中浮空，离地 16 px。
- **HP** 2900，**韧性** 120。
- **场地**：幻宫天台，平地，两侧会出现他召唤的镜子。

| 阶段 | 招式 | 预警 | 应对 |
|---|---|---|---|
| 一 | 蜃光弹：挥扇打出三道紫色光弹 | 扇子展开，白 | 格挡或走位 |
| | 幻镜：在场地两侧召出镜子，他的光弹会在镜子之间来回反弹 | 镜子浮现 | 打碎镜子（每面 3 下） |
| | 分身：分出 4 个分身，绕着玩家转圈后同时出招，只有真身有影子 | 紫 | 看影子，或用照夜 |
| | 紫雷：场上依次落下竖直雷柱 | 地面出现紫圈 | 走位 |
| 二（50%） | **蜃气潮**：全场变黑，只有照夜的光圈和敌人的眼睛看得见，持续 12 秒 | 转阶段 | 保持照夜常亮（这一阶段照夜冷却减半） |
| | 海市：一部分地板看起来塌了，其实是幻象；另一部分看起来完好，其实是真的缺口 | 紫 | 用照夜分辨 |

### B6 蜃龙（第 5 章，二阶段）

- **外形**：巨大的蛟龙，头顶是扇贝一样的巨大冠壳，身躯在云海里时隐时现。画面里只完整出现头和前爪，嘴里不断吐出紫色蜃气。
- **HP** 3500；不会破韧，只有头部能受伤。
- **场地**：崩塌中的云海浮台，3～4 块上下漂移的浮台，下面是云海。掉下去扣 15% 血，然后在最近的浮台上复活。
- **玄霜支援**：每 25 秒冻结蜃龙 4 秒（画面转冷，冰晶炸开），这是主要的输出窗口。此时剑意满按 O，会触发「照夜·霜月」合击，伤害 ×1.5。

| 招式 | 预警 | 应对 |
|---|---|---|
| 龙息扫射：从左到右扫过整个画面 | 张嘴蓄力 60f，红 | 跳到最高的浮台上方，或躲到浮台下方 |
| 咬台：扑向一块浮台，咬住 3 秒 | 头部后仰，白 | 离开那块浮台；它咬住时头就是固定靶 |
| 尾扫：尾巴从云里横扫，把浮台上的玩家扫下去 | 云层翻涌，白 | 跳 |
| 蜃气球：追踪弹 | 白 | 用剑气抵消 |

- **终结**：血量归零后进入封印演出（按住 J 把剑插下去，不会失败）。
