# 音频

## 音乐

**风格**：国风乐器（古筝、竹笛、琵琶、二胡、大鼓）加电子打击乐。

**分层配乐**：每章一首探索曲。进入锁屏战时叠加一层鼓组（同一首曲子的另一条音轨，淡入），战斗结束再淡出。探索和战斗之间切换不生硬。

| 曲目 | 用途 | 气质 |
|---|---|---|
| 标题 | 标题画面 | 古筝独奏，空灵 |
| 青崖 | 第 1 章探索 / 战斗层 | 急促的琵琶，火场的压迫感 |
| 竹雾 | 第 2 章 | 竹笛，潮湿，神秘 |
| 断岳 | 第 3 章 | 低沉的大鼓，古老 |
| 幽泽 | 第 4 章 | 二胡加异域打击乐，诡异里带温情 |
| 村落 | 第 4 章魔族村落 | 轻快温暖，全作唯一明亮的曲子 |
| 蜃楼 | 第 5 章 | 合成器 + 古琴，梦幻扭曲 |
| Boss 通用 | 第 1～3 章 Boss | 鼓 + 琵琶轮指 |
| 骨刹 | 第 4 章 Boss | 悲壮 |
| 蜃楼 / 蜃龙 | 最终战 | 两段，二阶段加入人声吟唱 |
| 营地 | 营地 | 古筝，休憩 |

**来源**：
- 原型阶段：用 CC0 素材做占位，每一条都记录来源和授权。
- 正式版：委托作曲，或购买可商用的国风曲库。

## 音效

原型阶段用 WebAudio 程序合成（类似 jsfxr），正式版换成采样。

| 类别 | 音效 | 备注 |
|---|---|---|
| 挥剑 | 轻挥 3 种变体、重挥、蓄力（循环） | 变体随机播放，避免听腻 |
| 命中 | 肉体、石头、骨头、幻象（玻璃碎裂感）、木头 | 按敌人材质区分 |
| 防御 | 格挡「叮」、弹反「锵」+ 混响、破防 | 弹反要给最强的满足感 |
| 移动 | 脚步（土、木、石、水）、跳、落地、闪步破风声 | |
| 特技 | 每个特技一个专属音效 | 起手音短，命中音响 |
| 照夜 | 清亮钟鸣 + 玻璃质感的扩散音 | 本作的「标志声音」 |
| 奥义 | 起手蓄势（全场静音 0.3 秒）→ 连斩 → 末击巨响 | 用「静」衬「响」 |
| 敌人 | 每种敌人：预警音（和预警色配套）、攻击、受击、死亡 | 红光预警一定要有独特的警示音 |
| UI | 选择、确认、返回、获得物品、升级 | 用木鱼、铃铛一类的音色 |

## 混音原则

- 优先级：玩家命中 > 预警音 > 敌人攻击 > 其他。
- 同一个音效同时最多播放 3 个。
- 奥义期间音乐压低 60%。
- 设置里提供：总音量、音乐、音效，以及「预警音增强」（辅助功能）。
