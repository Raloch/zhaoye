# 界面与交互

## 视觉风格

宣纸底、墨字、朱砂点缀，整体像一幅卷轴。按钮用毛笔笔触做底，选中项左侧盖一枚朱砂小印。


| 元素 | 位置 | 说明 |
|---|---|---|
| 头像 | 左上 | 朱砂印章样式，刻一个「昭」字 |
| 生命条 | 左上 | 朱红色；受伤时先变白再慢慢退去，能看出刚才挨了多少 |
| 灵力条 | 左上 | 青碧色；灵力不够放特技时闪烁 |
| 剑意 | 左上 | 5 格金色，满了发光并提示「O」 |
| 灵石 / 道具 | 右上 | 当前道具、数量、按键提示 |
| 连击数 | 右侧中部 | 毛笔数字；评级印章（初、巧、妙、绝、神）盖下来时「啪」的一下 |
| Boss 血条 | 底部居中 | 书法名字、阶段分割线、韧性条 |
| 伤害数字 | 跟随敌人 | 可以在设置里关掉；暴击是红色大字 |
| 按键提示 | 场景内 | 教学时以墨迹字浮现在场景里，例如「K 跳」，不弹窗 |

**辅助功能**：HUD 缩放（80%～130%）、关闭屏幕震动、降低闪光（冲击帧改为压暗）、色弱模式（红、紫预警加上形状区分：红是三角「危」，紫是圆环）。

## 菜单流程

```
标题 ─┬─ 开始 → 选择难度 → 第 1 章
      ├─ 继续 → 世界地图 / 营地
      ├─ 设置
      └─ 制作人员

营地：商店（小蝠）｜悟道（升级招式）｜饰品｜试剑（重玩遭遇战）｜出发（世界地图）
暂停：继续｜招式表｜设置｜回营地
```

- **标题画面**：水墨山水缓缓推移，叶昭的剪影立在崖边，发带飘动；「照夜封魔录」书法大字，按任意键时一道剑光划过标题。
- **招式表**：暂停菜单里随时能看。每个招式有指令图示、说明和一段循环演示（直接用游戏内的骨骼动画播放）。连招游戏必须有这个。
- **章节结算**：卷轴展开，列出用时、最高连击、受伤次数、招式多样性，最后盖一枚评级大印（甲、乙、丙、丁）。

## 对话

- 底部宣纸对话框，左右两侧是说话人的剪影半身像，带各自的点缀色。
- 正在说话的人亮，另一方暗。
- J 或回车推进；按住 Esc 1 秒跳过整段剧情。
- 关卡内的气泡对话不打断操作，同时最多显示一个。

## 设置

| 项 | 选项 |
|---|---|
| 音量 | 总音量、音乐、音效 |
| 按键 | 键盘重映射；手柄 |
| 操作辅助 | 快捷技能（数字键放特技，灵力 +20%）；指令宽容度（标准 / 宽松） |
| 画面 | 屏幕震动（关 / 弱 / 标准）；闪光强度；伤害数字开关；HUD 缩放 |
| 辅助 | 色弱模式；预警音增强 |
