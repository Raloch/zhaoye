# 美术规范

## 1. 风格：水墨剪影 + 霓光剑气

**一句话**：角色是近黑的剪影，背景是远淡近浓的水墨山水，画面上发亮的只有剑光、眼睛、点缀色和特效。

**参考**：《影之刃》（国风剪影 + 连招）、《忍者必须死》（剪影 + 水墨）、《Shadow Fight 2》（剪影格斗的动作可读性）、《Limbo》（剪影与景深层次）。

### 为什么选这个风格

1. **能量产**：剪影只要轮廓对，不用画五官、衣褶和光影。角色用「骨骼 + 部件」做程序动画，一套骨架就能给所有人形角色做 40 个动作，不用逐帧手绘。
2. **打击感清楚**：黑色剪影上一道青白剑光，对比度最高，动作最好读。
3. **题材契合**：仙侠配水墨，天然合拍。
4. **性能友好**：大面积纯色填充，Canvas 2D 画起来很快。

### 如果改用像素风

也可以，但每一帧都得画。主角 40 个动作 × 平均 6 帧 ≈ 240 帧，再加 10 种杂兵和 6 个 Boss，总共要 800～1200 帧。要么请美术，要么买素材包，而素材包很难统一风格。如果你有美术资源或者更喜欢像素风，告诉我：玩法设计不用动，只需要换掉美术规范和渲染层。

## 2. 三条硬规则

1. **剪影能认人**：每个角色缩小到 1/4 的纯黑轮廓，也得能认出是谁。设计时先定轮廓，再加细节。
2. **亮色只给信息**：高饱和亮色只用在剑光、敌人眼睛、预警、可交互物和点缀色上，背景一律低饱和。
3. **游戏层对比度最高**：角色接近纯黑，背景是中到浅的灰调，越远越淡（远淡近浓）。

## 4. 尺寸

逻辑分辨率 **480×270**（16:9），整数倍放大（2 倍 960×540，4 倍 1920×1080）。角色是矢量剪影，按实际分辨率绘制，不做像素化，边缘清晰。

| 类别 | 高度（逻辑像素） | 例子 |
|---|---|---|
| 主角 | 44 | 叶昭 |
| 小型 | 16～32 | 鬼火、小蝠、灰狼（体长 40） |
| 中型 | 40～64 | 狼卫、骷髅兵、石傀儡 |
| Boss | 60～140 | 骨刹 60、黑鬃 72、镇岳 128、枯藤姥姥 140 |
| 巨型 | 超出画面 | 蜃龙（只露出头和前爪） |

## 5. 角色制作：骨骼 + 部件

### 人形骨骼

```
                头
                │ 颈
  远侧上臂 ─── 胸 ─── 近侧上臂
     │          │          │
  远侧前臂     脊柱     近侧前臂 ── 武器
                │
               髋（根节点）
             ╱      ╲
       远侧大腿      近侧大腿
          │              │
       远侧小腿      近侧小腿
          │              │
        远侧脚        近侧脚
```

- 所有人形角色共用这套骨骼，只改骨骼长度、粗细和部件。
- **姿势** = 每根骨骼的绝对角度（0° 朝正下，正值朝面朝方向转）。
- **动画** = 若干关键姿势 + 每段帧数 + 缓动曲线。帧数直接对应战斗文档里的起手、判定、收招。

### 部件

| 部件 | 做法 |
|---|---|
| 四肢、躯干 | 程序生成的胶囊，两端半径不同（大腿粗、脚踝细） |
| 头 | 椭圆 + 发型路径 |
| 头发、发带、衣摆、披风 | 3～6 个点组成的软链，每帧用 Verlet 物理模拟，随动作甩动 |
| 武器 | 固定形状的路径，挂在手上 |
| 特征件 | 角、冠、鬃毛、盾、拂尘等，用 SVG path 字符串定义（Canvas 的 `Path2D` 可以直接吃） |

**软链二次动画是这个风格的灵魂**：叶昭的发带、马尾、衣摆随动作甩起来，连待机都显得生动。这部分只在渲染层计算，不影响战斗逻辑。

### 非人形

狼、蛾、蛙、树、龙各有专用骨骼。例如四足：躯干 + 颈 + 头 + 4 条腿 × 2 节 + 尾巴软链。

### 主角动画清单

| 分类 | 动画 | 帧数 |
|---|---|---|
| 移动 | 待机（呼吸）、走、疾跑起步、疾跑、急停、转身 | 循环 / 8 / 6 |
| 跳跃 | 起跳、上升、顶点、下落、落地、二段跳翻身 | 由物理决定 |
| 普攻 | 青锋一至四、蓄力（循环）、蓄力斩 | 按帧数据 |
| 指令技 | 上挑、扫堂、冲刺斩、空斩一至三、坠星（下冲 + 落地） | 按帧数据 |
| 特技 | 穿云刺、剑气·破月、升龙斩、疾风连斩、镇地剑 | 按帧数据 |
| 防御 | 格挡（持续）、格挡被击、弹反、回风、闪步 | 按帧数据 |
| 其他 | 照夜、奥义起手、奥义收刀、受击（轻/重）、击飞、倒地、起身、受身、死亡、交互、胜利收剑 | —— |

合计约 40 个动画，每个 2～5 个关键姿势，总共约 150 组姿势数据，全部是纯数据。

## 6. 背景制作：程序化水墨

- **山脊**：多倍频一维噪声生成山脊线，下方用「浓 → 淡」的竖直渐变填充，模拟墨色晕开，边缘加细噪声毛边。
- **远近**：三层山，越远越淡、越偏环境色、越矮。
- **雾**：几条横向半透明渐变带，缓慢漂移。
- **章节标志物**：
  - 第 1 章：飞檐屋顶、牌坊、远塔、烟柱、火光。
  - 第 2 章：竹子（竹节 + 竹叶笔触，程序生成）。
  - 第 3 章：竖直断崖、镇魔碑、吊索桥。
  - 第 4 章：沼泽倒影、枯树、磷火、天边的海市蜃楼。
  - 第 5 章：漂浮的宫殿碎块、金边、镜面。
- 背景在加载时画到离屏画布，运行时只做贴图和平移，开销很小。
- 用种子随机数生成，同一个种子每次画出来都一样。

## 7. 特效

| 特效 | 做法 |
|---|---|
| 剑光拖尾 | 记录剑尖最近 N 帧的位置，连成一条渐隐弧带，叠加混合（`lighter`） |
| 墨溅 | 命中点炸出 8～20 个墨点粒子，带拖尾，落地后晕开消失 |
| 斩痕 | 命中瞬间一道青白色月牙闪光，持续 4 帧 |
| 照夜光 | 径向渐变光圈；圈内把幻象图层切换为「真相」图层 |
| 蜃气 | 紫色噪声雾团，缓慢翻滚 |
| 冲击帧 | 奥义末击、击杀 Boss 时全屏黑白反转 2 帧（动画常用的「冲击帧」手法，剪影风格下效果特别好） |
| 环境粒子 | 火星（第 1 章）、竹叶（第 2 章）、碎石灰（第 3 章）、萤火（第 4 章）、金色光尘（第 5 章） |
| 预警 | 白：轮廓闪白；红：轮廓发红光，头顶出现「危」字；紫：紫色描边加残影 |
