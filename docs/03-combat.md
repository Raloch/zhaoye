# 战斗系统

> 帧数一律按 60 帧/秒计，距离单位是逻辑像素（画面逻辑分辨率 480×270，主角身高 44）。所有数值都是初版，要在 M1 战斗原型里实际调。

## 1. 操作

### 键位（默认，可重映射）

| 键 | 作用 | 备注 |
|---|---|---|
| A / D | 左右移动 | 快速按两下进入疾跑 |
| W | 上方向（指令用） | 在 NPC 或门前按 W 交互 |
| S | 下方向（指令用） | S+K 从单向平台跳下 |
| J | 攻击 | 按住蓄力 |
| K | 跳跃 | 空中再按是二段跳（第 2 章解锁）；被击飞时按 K 受身 |
| L | 格挡 | 按住格挡；恰好在受击前按下是弹反；L+A/D 闪步 |
| U | 照夜 | 破幻光（第 1 章末解锁） |
| I | 使用道具 | 使用当前选中的道具 |
| Q | 切换道具 | |
| O | 奥义 | 剑意满时发动 |
| Esc | 暂停 / 招式表 | |

**手柄（M6）**：左摇杆或十字键控制方向，X 攻击，A 跳，RB 格挡，Y 照夜，LB 道具，RT 奥义。

### 方向是相对朝向的

指令里的 `→` 指**面朝的方向**，`←` 指背后。角色面朝左时，A 就是 `→`。

## 4. 指令识别

输入层记录每一帧的按键状态（保留最近 30 帧）。指令识别是一个纯函数：`recognize(history, facing) → 招式 | null`。

**规则**：

1. 方向只记「按下」的那一刻，不看按住状态。`↓→` 是先按下 S，再按下面朝方向的键。
2. 相邻两个方向按下的间隔 ≤ 12f；最后一个方向到 J 的间隔 ≤ 10f。
3. 允许斜向过渡：输入 ↓→ 的过程中 S 和 D 短暂同时按住也算。
4. 按从长到短、从特殊到一般的顺序匹配：
   `↓↓J > ↓↑J > ↓→J > ←→J > →→J > 空中↓J > ↑J > ↓J > 疾跑中J > J`
5. 灵力不够时降级为普通技（比如 ↓→J 灵力不够就当作普通的 J），灵力条闪烁提示。
6. **→→J 与冲刺斩的区分**：第二次按下 → 后 12f 内按 J，出疾风连斩；疾跑持续 12f 以上再按 J，出冲刺斩。

**穿云刺为什么用 ←→J，而不是参考作的 →+J**：玩家跑着跑着就会按攻击。如果「按住 → 再按 J」就出特技，每次跑动中攻击都会误出招，白白扣灵力。「先后再前」是主动输入，不会误触。

## 5. 连段规则

### 取消表

| 从 ↓ ＼ 取消到 → | 普攻下一段 | 上挑/扫堂 | 特技 | 奥义 | 跳跃 | 闪步 |
|---|---|---|---|---|---|---|
| 普攻（命中或被挡） | ✔ | ✔ | ✔ | ✔ | —— | ✔（10 灵力） |
| 普攻（挥空） | ✔ | —— | —— | —— | —— | ✔（10 灵力） |
| 上挑（命中） | —— | —— | ✔ | ✔ | ✔ | —— |
| 特技（命中） | —— | —— | 只有穿云刺能再接其他特技 | ✔ | 升龙斩可以 | —— |
| 空斩 | 下一段空斩 | —— | 空中剑气 | ✔ | 二段跳 | —— |

- **取消窗口**：从判定第 1 帧到收招第 8 帧。
- **输入缓冲**：取消窗口打开前 8f 内按下的键会被记住，窗口一开立刻执行，连打不吃键。

### 敌人的受击状态

| 状态 | 触发 | 说明 |
|---|---|---|
| 硬直 | 普通命中 | 不能行动，可以继续挨打 |
| 浮空 | 挑空类招式 | 受重力下落，空中可以被追打 |
| 击倒 | 扫堂、击落、击飞后落地 | 倒地 40f，只吃「追地」攻击（坠星、镇地剑），一段连击只能追地 1 次 |
| 地面弹起 | 坠星、镇地剑打中浮空或倒地的敌人 | 弹回空中，一段连击 1 次 |
| 墙弹 | 穿云刺、断岳把敌人打到锁屏边界 | 从边界弹回来，一段连击 1 次 |
| 破韧 | 韧性被打空（大型敌人和 Boss） | 虚弱 3～4 秒，受到的伤害 +30% |

### 防止无限连

- **浮空重力修正**：敌人在空中每挨一下，重力 +6%；空中累计挨满 15 下后自动受身落地。
- **伤害修正**：同一段连击的第 20 下起伤害 ×0.8，第 40 下起 ×0.6。
- **一段连击的定义**：从敌人第一次进入硬直开始，到它恢复自由行动为止。

### 连段范例

```
入门  J J J J
挑空  J J ↑J → K → 空J 空J 空J → 坠星（空中↓J）
中级  J J ↑J → K → 空J 空J → 二段跳 → 空J 空J → 坠星 → 弹起 → ↑J → ↓→J
反击  弹反 → J（回风）→ ←→J（穿云刺）→ 墙弹 → J J ↑J …
高级  J J J ↑J → K → 空J×2 → 二段跳 → 空J×2 → 坠星 → 弹起
      → ↓↑J（升龙斩）→ 跳跃取消 → 空J×2 → O（奥义收尾）
破韧  （Boss 破韧后）蓄力斩 → →→J（疾风连斩）→ ↓↓J（镇地剑）→ 弹起 → ↑J …
```

## 6. 伤害与资源

### 伤害公式

```
伤害 = 攻击力 × 招式倍率 × 连击修正 × 暴击(1.5) × (1 − 目标减伤) × 浮动(0.95～1.05)
```

- 基础暴击率 5%；回风必定暴击。
- 浮动值来自注入的种子随机数，保证能回放。
- 目标处于破韧状态时，受到的伤害 ×1.3。

### 灵力（MP）

- 上限 100，随等级提升（见 [09-systems.md](09-systems.md)）。
- 回复：每秒自动 +2；普攻命中 +1.5；弹反 +8。
- 设计意图：特技要「靠打出来」。持续进攻、打出弹反就能源源不断地放特技，站着不动回得很慢。

### 剑意（大招槽）

- 上限 100，满了按 O 放奥义。
- 获取：每次命中 +1 × 评级倍率；弹反 +10；受伤时获得「损失血量百分比 × 0.3」（挨打也能涨一点）。
- **连击评级**（屏幕右侧的印章）：

| 评级 | 条件 | 剑意倍率 |
|---|---|---|
| 初 | 连击开始 | ×1.0 |
| 巧 | 同一段连击里用过 2 种招式 | ×1.2 |
| 妙 | 3 种 | ×1.5 |
| 绝 | 4 种，且连击 ≥ 20 | ×2.0 |
| 神 | 5 种，且连击 ≥ 35 | ×3.0 |

同一招连续用 3 次以上，评级分会衰减。目的是鼓励玩家换着招打，而不是一直按 J。

## 7. 打击感参数

| 参数 | 普攻 | 重击（断岳、蓄力斩、特技末段） | 奥义末击 |
|---|---|---|---|
| 顿帧（双方同时定格） | 3f | 6f | 12f |
| 屏幕震动 | 无 | 3 px，8f | 6 px，16f |
| 受击闪白 | 2f | 2f | 4f，外加全屏黑白反转 2f |
| 命中特效 | 小墨溅 + 青色斩痕 | 大墨溅 + 冲击环 | 全屏墨溅 |
| 慢动作 | 无 | 无 | 击杀 Boss 时 0.3 倍速持续 1 秒 |

另外：
- 攻击命中时，玩家招式自带的前冲位移减半，打起来有「吸住」的感觉。
- 敌人被击飞时，飞行轨迹上拖一道墨痕。
- 顿帧只停逻辑层，渲染层的粒子、发带继续动，画面不会像卡住一样。

## 8. 敌人预警色（全局规则）

| 颜色 | 含义 | 应对 |
|---|---|---|
| 白闪 | 普通攻击 | 可格挡、可弹反 |
| 红光 + 「危」字 | 不可格挡 | 闪步，或在起手时打断 |
| 紫光 | 幻术攻击：可能是假的，也可能从别处打来 | 用照夜照破 |

普通难度下，预警至少提前：白 18f，红 30f，紫 24f。简单难度延长 50%，困难难度缩短 25%。

## 9. 玩家受击

- 普通受击：硬直 20f，击退 8 px。
- 重击：击飞，落地前可以受身。
- 倒地起身：起身时有 60f 无敌，避免被压着起身打。
- 死亡：回到最近的检查点（灯笼），保留经验和灵石。Boss 战从 Boss 开场重来，剧情对话可跳过。
